# RAGIS — Protótipo de demonstração

Protótipo estático de demonstração para o hackathon GovTech Inova Paraíso.

**Aviso:** Todos os dados apresentados são sintéticos. O site não possui integração com backend, GPS real, órgãos de segurança ou despacho operacional. Os estados de demonstração podem ficar armazenados localmente no navegador; não representam sincronização real entre dispositivos.

1. Crie um repositório público chamado `ragis-prototipo` na conta `gabrielh063`.
2. Envie `index.html`, `.nojekyll` e `README.md` para a branch `main` na raiz do repositório.
3. Em **Settings → Pages → Build and deployment**, escolha **Deploy from a branch**, `main`, `/(root)` e clique em **Save**.
4. Depois da publicação, confira o endereço em **Settings → Pages**. O endereço esperado é `https://gabrielh063.github.io/ragis-prototipo/`, sujeito a configuração e disponibilidade.
5. Teste em tablet e celular, e compartilhe apenas o endereço confirmado.

Para testar offline, abra `index.html` em um navegador. Para simular compartilhamento de estado entre duas abas, sirva o diretório com `python3 -m http.server 8000 --bind 127.0.0.1` e abra `http://127.0.0.1:8000/` em duas abas do mesmo navegador.
